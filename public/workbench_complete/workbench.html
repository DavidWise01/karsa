// recursive memory — real, runnable infrastructure

Local git ↔ central database

An append-only memory store. Each local node keeps a hash-chained, git-committed log and syncs to a central database that re-verifies every chain. Entries are Ed25519-signed, so the server can prove not just that data is intact but who wrote it. A built-in operator dashboard makes it all inspectable.

append + git commit→ sign Ed25519→ push to central→ verify chain + signatures→ dashboard inspect
# in the recursive_memory/ package directory pip install -r requirements.txt python launch.py # starts central, seeds nodes, opens the dashboard # then open http://localhost:8000/

The dashboard (served at /) lists every node with a signed/unsigned lock, shows each chain entry with its id↔parent links, payload, recursive state digest and signature status, and verifies any chain server-side with one click. Tests prove append→git→push→multi-node→restore→tamper-rejection and signature-forgery rejection.

// the through-line

What ties it together

Across all three groups runs one idea: a state that commits to its own history. The Bell test commits a measurement to a provable correlation; the kernel folds each tunnel into its seed; the memory chain folds each entry's digest into the next. Different domains, same shape — state(n) = f(input, state(n−1)) — and in every case the claim is only ever as strong as what can be checked.

Honest scope — held throughout

  • Instruments visualize established science (Brus, Aharonov–Bohm, Bell/CHSH, Bloom). Every number is checked against its closed form. They are teaching tools, not lab metrology.
  • Defensive visualizers are schematic studies. The geometry and bit-logic are real where stated; the "energy" is illustrative, not a physical or strategic claim.
  • The memory system is real infrastructure. "Memory" = stored state with verifiable lineage. The hash chain proves integrity and order; signatures prove authorship-by-key — not sentience, not real-world identity.
  • Nothing here asserts discovery of, or ownership over, any natural law or general concept.
